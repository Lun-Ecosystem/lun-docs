Lun'Acedia · À valider

Planche 4. La file des propositions de l’IA restées sous le seuil. Mêmes briques que la planche Mail : rail, rangées, carte de proposition, menu flottant, jetons B.

Références : le triage de Linear (une file qu’on vide au clavier, un élément après l’autre), Gmail (annulation par un toast après chaque action), myBrain (état vide soigné qui dit ce qui s’est passé). But : vider la file en moins d’une minute, sans ouvrir chaque mail.

1 · File groupée par boîte proposée

Les propositions sont regroupées par destination : on valide un lot entier d’un clic quand la confiance est bonne. Chaque carte dit où, pourquoi et à quel point l’IA est sûre. La carte active (au clavier) est surlignée ; V valide et passe à la suivante. Après chaque action, un toast propose d’annuler.

Ce qui change de fond

  • Regroupement par boîte proposée et validation par lot.
  • Seuil rappelé en tête : on comprend pourquoi ces mails attendent.
  • Toute action s’annule par le toast ou Z.
  • File vide qui résume l’activité de l’IA.

Clavier

  • J K carte suivante, précédente
  • V valider · C corriger · ↵ ouvrir le mail
  • Maj V valider le lot · Z annuler

À trancher

  • « Retenir pour cet expéditeur » crée une règle (les règles existent déjà dans Réglages) : coché par défaut ?
  • Le seuil du bouton « Tout valider au-dessus de » : fixe à 85 % ou réglable.
  • La ligne « pourquoi » reste liée à la justification du classifieur.
