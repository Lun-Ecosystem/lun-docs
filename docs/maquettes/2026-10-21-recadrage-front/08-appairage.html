2 · Autoriser Lun'Anima

Quand une application demande l’accès depuis un navigateur pas encore relié, le parcours compte deux étapes, affichées en haut : 1 relier ce navigateur (carte ci-dessus), 2 autoriser. L’écran d’autorisation montre qui demande, ce qu’il pourra faire, et où le navigateur repartira. « Refuser » est un vrai bouton de même taille, à côté d’« Autoriser » : pas de lien caché, pas de piège.

Ce qui change

  • Forme seulement : mêmes codes, mêmes étapes, mêmes droits.
  • Étapes visibles quand une application attend.
  • Commande copiable, code groupé par trois partout (page, Réglages, console).

Sécurité inchangée

  • Code à usage unique, expiration, verrouillage après échecs.
  • Le message d’erreur ne dit pas si le code a existé.
  • Seul un clic explicite envoie la décision.

À trancher

  • Logos des mondes (A rouge Anima, Ac bleu Acedia) : provisoires, en attendant de vrais pictogrammes Lun'.
